# SENALAB — Projeto INFEM

Laboratório independente de estratégias, simulações e experimentos estatísticos aplicados a loterias.

## INFEM

INFEM é o núcleo experimental do SENALAB.

Objetivo: estudar resultados históricos, testar hipóteses e comparar estratégias por meio de simulações e backtests, sempre separando desempenho histórico de capacidade real de previsão.

### Metodologia

- Análise de resultados históricos
- Simulações em larga escala
- Backtests
- Comparação com controle aleatório
- Registro de experimentos antes do sorteio
- Medição de acertos, erros e retorno
- Preservação dos resultados, inclusive testes que falharem

## Princípio do projeto

Nenhum resultado passado será tratado como garantia de resultado futuro.

O objetivo do INFEM é descobrir, através de testes reproduzíveis, se alguma estratégia apresenta desempenho estatisticamente diferente do acaso.
