# INFEM — Experimentos

Esta pasta contém os experimentos realizados pelo INFEM.

Cada experimento deve ser registrado antes do resultado do concurso utilizado para testá-lo.

## Regras

- Registrar a hipótese antes do sorteio.
- Registrar os jogos gerados pelo método.
- Criar um grupo de controle aleatório.
- Congelar os jogos antes do resultado.
- Não alterar os jogos após o congelamento.
- Registrar o resultado oficial.
- Comparar o desempenho do método com o controle.
- Registrar a conclusão, mesmo quando o resultado for negativo.

## Objetivo

Construir um histórico de experimentos reproduzíveis para verificar se alguma estratégia apresenta desempenho estatisticamente diferente do acaso.
