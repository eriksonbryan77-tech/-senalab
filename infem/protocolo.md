# INFEM — Protocolo Experimental

## Objetivo

Testar hipóteses e estratégias aplicadas a loterias por meio de experimentos reproduzíveis, simulações e backtests.

O objetivo não é assumir que resultados futuros possam ser previstos, mas verificar se algum método apresenta desempenho estatisticamente diferente de um controle aleatório.

## Regra principal

Toda hipótese deve ser registrada antes do resultado utilizado para testá-la.

Nenhuma aposta ou previsão poderá ser alterada depois de congelada.

## Estrutura dos testes

Cada experimento deverá conter:

- Hipótese
- Método utilizado
- Jogos gerados
- Grupo de controle aleatório
- Data de criação
- Concurso-alvo
- Resultado oficial
- Quantidade de acertos
- Comparação com o controle
- Conclusão

## Princípio INFEM

Hipótese → Registro → Congelamento → Resultado → Comparação → Conclusão
